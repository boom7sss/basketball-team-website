# 内容维护说明

## 后台入口

本地后台：

```text
http://localhost:3000/admin
```

默认密码：

```text
team-admin-2026
```

正式上线建议通过环境变量 `ADMIN_PASSWORD` 修改密码。

## 保存规则

后台修改后需要点击：

```text
保存全部
```

保存后的公开内容会写入：

```text
data/site-data.json
```

报名信息也保存在同一个文件里，但不会通过 `GET /api/site` 暴露给前台。

## 首页内容

后台位置：

```text
首页模块
```

可管理：

- 下一场比赛标题和内容
- 最近赛果标题和内容
- 训练时间标题和内容
- 球队数据板块标题、说明、按钮文字
- 球队数据四张卡片的数值和标签
- 近期动态板块标题、说明、按钮文字
- 队员风采板块标题、说明、按钮文字
- 首页展示的三个球员

注意：近期动态显示的是新闻列表中排序靠前的新闻，具体新闻内容在“新闻动态”里改。

## 赛程战绩

后台位置：

```text
赛程战绩
```

每条比赛可管理：

- 日期
- 时间
- 对手
- 地点
- 赛事
- 状态：`upcoming` 或 `finished`
- 结果
- 我方得分
- 对方得分
- 摘要

建议：

- 未比赛：状态填 `upcoming`
- 已比赛：状态填 `finished`，并补比分

## 队员阵容

```text
队员阵容
```

每名队员可管理：

- 姓名
- 号码
- 队员状态：现役/退役
- 位置
- 年级
- 专业
- 身高
- 标签
- 简介
- 详情标题
- 详细介绍
- 赛场角色
- 个人语录

## 新闻动态

```text

```

每条新闻可管理：

- 标题
- 分类
- 日期
- 封面地址
- 轮播照片地址
- 公众号原文链接

说明：

## 上传素材

后台中带有“封面地址、照片地址、图片地址、素材地址、轮播照片地址”的字段旁会显示上传按钮。

支持格式：

- 图片：jpg、jpeg、png、webp
- 视频：mp4、webm、mov

上传规则：

- 图片会自动转成 `.webp`
- 图片最大边控制在 1920px 内
- 图片质量为 86
- 视频不会自动压缩
- 上传后会自动填入 `/assets/uploads/...` 地址
- 上传后仍然需要点击“保存全部”

## 手动填写素材地址

如果不使用上传按钮，手动填写时应使用网站路径，例如：

```text
/assets/gallery/highlights/photos/highlight-photo-1.webp
```

不要填写 Windows 绝对路径，例如：

```text
D:\球队网站\影像素材\比赛集锦\照片\xxx.jpg
```

浏览器访问的是服务器公开路径，不认识你电脑上的绝对路径。

## 当前仍写死在代码里的内容

以下内容目前不在后台管理中：

- 顶部导航栏目：`public/app.js` 的 `navItems`
- 影像中心四个大板块：`gallerySections`
- 比赛集锦下的“比赛照片/比赛视频”：`gallerySubsections`
- 后台栏目顺序：`adminTabs`
- 页面文案默认值：`pageDefinitions`
- 部分新增条目的默认内容：`factories`
- 登录页说明文字和默认密码提示

建议后续迁移：

- 导航迁移到 `data/site-data.json` 的 `navigation`
- 影像板块迁移到 `data/site-data.json` 的 `gallerySections`
- 页面结构型内容迁移到 JSON，长文章可考虑 Markdown
- 后台字段配置仍可保留在代码中，避免非技术负责人误改字段结构

## 原始素材与部署素材

原始素材：

```text
球员照片
影像素材
```

网站部署素材：

```text
public/assets
```

建议负责人保留原始素材库，但部署时只上传 `public/assets`，避免服务器包体过大。

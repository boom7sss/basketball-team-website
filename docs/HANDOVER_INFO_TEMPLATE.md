# 官网交接信息填写模板

本文用于实际交接时填写。请不要在本文档中写入真实密码、`SESSION_SECRET`、服务器登录密码、SSH 私钥、云服务账号密码或域名账号密码。

密码、密钥和账号密码只通过可信渠道交接。
